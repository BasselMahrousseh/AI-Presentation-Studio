# e& Universal template

This package keeps the supplied company deck as `e-and-universal-source.pptx` and provides the AI-ready template definition used by Presenton.

Supported reusable layouts: cover, agenda, section divider, narrative, KPI summary, full-chart, table, chart-plus-table, process/roadmap, and closing. The chart layouts may use any chart type supported by the application: area, bar, bubble, donut, horizontal bar, horizontal stacked bar, line, pie, polar area, radar, scatter, and stacked bar.

The source deck remains editable in PowerPoint. The JSON layout is what lets the generator fill text, lists, native tables, charts, and the progress infographic without breaking the e& visual system.
